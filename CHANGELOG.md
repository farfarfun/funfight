# Changelog

## [Unreleased]

### Changed

- **Breaking:** renamed the import name and PyPI package name from `notefight` to `funfight`
  to match the repository name. Anyone doing `import notefight` or `pip install notefight`
  must switch to `import funfight` / `pip install funfight`.
- The old `notefight` PyPI package will receive one final release forwarding to `funfight`
  (manual follow-up by the repo owner). Note: as of this change, neither `notefight` nor
  `funfight` has actually been published to PyPI yet.
